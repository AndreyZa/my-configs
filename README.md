# my-configs

Удобная оболочка на Ubuntu, WSL и macOS: zsh, Oh My Zsh, компактный
Powerlevel10k, поиск fzf, подсказки из истории и подсветка команд.
DevOps-инструменты устанавливаются отдельной опцией.

## Установка с чистой системы

### Ubuntu / WSL

```bash
sudo apt-get update
sudo apt-get install -y git ca-certificates
git clone https://github.com/AndreyZa/my-configs.git
bash my-configs/setup.sh
```

Скрипт запускают от обычного пользователя; для системных пакетов он использует
`sudo`. Если найдены прежние личные конфиги, в терминале появится выбор:
**1 — включить новые настройки с переносом личных дополнений и резервной копией**,
**2 — оставить текущие**.
Enter сохраняет текущую конфигурацию.

После активации откройте новый терминал или выполните в уже открытом окне:

```zsh
exec zsh
```

Работающая оболочка сама новые файлы не перечитывает.

### macOS — Apple Silicon и Intel

Если ещё нет Command Line Tools, выполните `xcode-select --install` и завершите
установку в появившемся окне. Затем:

```bash
git clone https://github.com/AndreyZa/my-configs.git
bash my-configs/setup.sh --bootstrap-homebrew
```

Флаг разрешает установку Homebrew через официальный установщик, если его ещё
нет. Существующий Homebrew используется автоматически, в том числе из
`/opt/homebrew`. При установленном Homebrew достаточно запуска без этого флага.

## Возможности

- Однострочный **lean**-промпт: каталог и Git слева, состояние команды и
  активных окружений справа. Другой стиль: `p10k configure`.
- Подсказки из истории: **→** или **End** принимает продолжение без выполнения
  команды; **Enter** запускает её.
- Подсветка команд, строк и синтаксиса во время набора.
- **Ctrl+R** — поиск команды в истории; **Alt+C** — выбор каталога.
  Для обеих ОС устанавливается одна закреплённая версия fzf со встроенной
  интеграцией; наличие файлов документации системного пакета не требуется.
- **Ctrl+Alt+F** — поиск файла. Стандартное **Ctrl+T** также доступно, если его
  не перехватывает приложение терминала.
- Общая история сессий: до 50 000 команд в памяти и на диске.
- Плагины DevOps-команд подключаются при наличии нужных программ. `tg`
  использует доступный `terragrunt`, без привязки к версии Snap.

## Шрифт и клавиши приложения терминала

Устанавливаются четыре начертания **MesloLGS NF**. На Ubuntu скрипт пытается
выбрать шрифт в доступных профилях GNOME Terminal/Ptyxis. Отсутствие
графической сессии не мешает установке оболочки.

На macOS выберите **MesloLGS NF** в профиле Terminal.app/iTerm2. В Terminal.app
включите **Use Option as Meta key**, чтобы Option-комбинации доходили до оболочки.
Обозначению Ctrl+Alt на Mac соответствует **⌃⌥**. В iTerm2 выберите
**Left Option key: Esc+**. Альтернативный ввод для поиска файлов — Esc, затем Ctrl+F.

В WSL шрифт устанавливается внутри Linux; Windows Terminal использует шрифты
Windows. При необходимости установите `.ttf` из `~/.local/share/fonts` в Windows
и выберите MesloLGS NF в профиле Ubuntu.

Если Ctrl+T открывает вкладку, используйте Ctrl+Alt+F. Примеры передачи клавиш:

- [Windows Terminal](terminal/windows-terminal-keybindings.json): добавить
  элементы в существующие `actions` и `keybindings`.
- [VS Code](terminal/vscode-keybindings.json): добавить элемент в пользовательский
  `keybindings.json`; он действует только при фокусе на терминале.

Примеры дополняют конфигурацию приложения, а не заменяют её целиком.

## Повторный запуск и личные настройки

```bash
bash my-configs/setup.sh --check
bash my-configs/setup.sh
```

Oh My Zsh и пользовательские дополнения сохраняются. Неизменённые управляемые
файлы обновляются повторным запуском. Для существующего личного или изменённого
вручную конфига сначала готовится версия рядом с суффиксом `.my-configs-new`.
В интерактивном терминале установщик предлагает включить её с резервной копией.
Отредактированные черновики сохраняются; новый кандидат получает отдельное имя.

Если выбран пункт «оставить» или запуск неинтерактивный, итог явно сообщает:
**«Настройки подготовлены, но не включены»**, и печатает точную команду активации.
`--check` также показывает это состояние как незавершённую установку.
Для явной замены без диалога с резервной копией:

```bash
bash my-configs/setup.sh --replace-config
```

При неизменной версии репозитория и исправной установленной среде обычный
повторный запуск не обновляет пакеты, не перезаписывает управляемые файлы и
ссылки, не пересоздаёт кеш шрифтов и не создаёт резервные копии. Недостающие
компоненты устанавливаются; DevOps-профиль восстанавливает свои повреждённые
CLI и ссылки по сохранённым версиям. Для базовых пакетов APT/Homebrew
установка недостающего может потребовать зависимостей пакетного менеджера.

Личные пути, алиасы и настройки конкретной машины размещайте в `~/.zshrc.local`.
При выборе активации или `--replace-config` установщик переносит туда личные
блоки старого `.zshrc`: функции, алиасы, переменные, пути, настройки SSH и клавиш.
Существующие локальные дополнения сохраняются и имеют приоритет; повторный
запуск не добавляет дубликаты. Старые версии обоих файлов остаются в backup.

Начальные настройки из старого конфига применяются перед Oh My Zsh, а остальные
— перед подсказками и подсветкой. Повторная загрузка самого Oh My Zsh, стандартного
промпта и интеграций fzf/подсветки не переносится. Установщик разбирает текст и
проверяет синтаксис через zsh, не выполняя пользовательский код. Для этого в базовые
зависимости входит Python 3.

Если личный код смешан с загрузкой оболочки в одном нераспознанном блоке, конфиг
содержит ошибку или нужно изменить `.zshrc.local`, являющийся символической ссылкой,
активация останавливается с объяснением и сохраняет действующие файлы. Новая версия
`.zshrc` остаётся рядом для просмотра. Неоднозначные блоки нужно разделить вручную.
Удаление строки из общего шаблона не превращается в обратную команду: чтобы
отключить общий алиас или переменную, задайте явный `unalias`/`unset` в `.zshrc.local`.

### Если конфиг уже заменили и команды пропали

После обновления репозитория выполните:

```bash
bash my-configs/setup.sh --restore-local
exec zsh
```

Команда выбирает последнюю резервную копию `.zshrc` в
`~/.local/state/my-configs/backup-*`, пропуская копии без `.zshrc` и известные чистые
шаблоны. Можно явно указать каталог нужной копии:

```bash
bash my-configs/setup.sh --restore-local "$HOME/.local/state/my-configs/backup-YYYYMMDDTHHMMSSZ.XXXXXX"
```

Восстановление объединяет старые дополнения с нынешними, сохраняя приоритет
текущих настроек, и подключает их через актуальный общий `.zshrc`. Пакеты и
инструменты не скачиваются, шрифт и оболочка входа не меняются. Повторное
восстановление той же копии не меняет уже восстановленные файлы.
Для другого каталога пользователя добавьте `--target-dir DIR`.

## DevOps-профиль

```bash
bash my-configs/setup.sh --devops
bash my-configs/setup.sh --devops --check
bash my-configs/setup.sh --devops --update
```

Профиль устанавливает kubectl, Helm, kubecolor, Terraform, Terragrunt и Ansible
через mise. Конфигурация профиля отделена от остальных настроек mise; настройки
конкретного проекта имеют приоритет. Python для Ansible изолирован.
Docker Engine/Desktop и Kubernetes-кластер профиль не разворачивает.

Если источник отдельного DevOps-инструмента отвечает **HTTP 404**, установщик
выдаёт warning, пропускает недоступный инструмент и продолжает остальные шаги.
При неудачном обновлении сохраняется прежняя рабочая версия, если она есть.
Отсутствующие инструменты не объявляются установленными: `--check` возвращает
ошибку для неполного профиля, а обычный повтор пытается установить пропущенное.
Ошибки проверки целостности, HTTP 403/500 и другие сбои по-прежнему останавливают
установку.

## Обновление и проверка

```bash
git -C my-configs pull --ff-only
bash my-configs/setup.sh --update
bash my-configs/setup.sh --help
```

Зависимости оболочки закреплены в репозитории. `--update` переводит управляемые
чистые Git-копии на версии из репозитория, сохраняя чужие изменения.
Этот же флаг разрешает обновление целевых базовых пакетов через APT/Homebrew.
Для DevOps-профиля добавьте `--devops`: проверяются свежие версии CLI, а профиль
и резервная копия меняются только при реальном изменении конфигурации.
Проверка новых версий может обновлять сетевой кеш менеджера инструментов.
Сам mise по-прежнему обслуживается системным APT/Homebrew.

Установка конфигурации в отдельный каталог:

```bash
bash my-configs/setup.sh --target-dir /tmp/my-configs-preview --no-chsh
```

Системные пакеты при этом всё ещё устанавливаются; если они уже доступны,
добавьте `--skip-packages`. Для отдельного каталога не меняется оболочка входа
и оформление действующего терминала.

CI проверяет Ubuntu и macOS Intel/Apple Silicon: синтаксис, поведение оболочки,
повторную установку, сохранение пользовательских изменений и загрузку настоящих
дополнений. Снимки управляемого дерева проверяют отсутствие перезаписей, изменений
прав, ссылок и времени модификации при обычном повторном запуске. Время чтения
файлов не учитывается; для явного `--update` отдельно допускается обновление
кеша проверки версий. Тесты с имитацией платформы дополняют проверки на
соответствующих ОС.
